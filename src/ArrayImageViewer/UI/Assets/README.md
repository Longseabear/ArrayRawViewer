# Generated Frame map icon

`frame-map-generated.png` was generated with the built-in image generation tool,
then refined with the same tool. It is embedded into both VS extension builds;
the viewer needs no external file or service. The image is decoded at 80 pixels
and displayed at 20 DIP. Standard navigation glyphs remain WPF vectors.

Initial prompt:

Use case: logo-brand. Asset type: ONE production toolbar icon PNG for Sensor RAW
Array Viewer, a Visual Studio extension. Primary request: a custom Frame Map icon.
A compact square image-frame outline with a tiny 2x2 Bayer mosaic inset and one
small selected rectangular region. Flat precise UI glyph, bold simple geometric
silhouette, rounded stroke ends. Pale ice-white #e8eef6 primary strokes and
turquoise #39d5b6 selected region. Genuine transparent background, no opaque
background, no checkerboard baked in. Entire single icon centered and fills about
85 percent of square canvas. Designed to remain recognizable when displayed at
20x20 pixels. No lettering, no shadows, no gradients, no perspective, no button
background, no thin intricate details, no other icons. Output just the icon asset,
not a presentation or mockup.

Refinement prompt:

Edit this UI icon into a much simpler production toolbar PNG. Preserve the idea
of a frame map for a RAW Bayer image viewer, but simplify radically: ONLY an
ice-white thick rounded square outline containing exactly four solid colored
squares arranged GR/BG (green red / blue green); one turquoise small L-shaped
corner mark overlapping lower right of outer frame indicates selected region.
Remove mountains, circles, extra crops, textures and all scattered speckles. Flat
opaque solid geometric colored strokes only, very clean hard smooth alpha edges.
The entire background and gaps must be genuinely fully transparent, with NO
residual speckles or dirt anywhere. NO gradients, shadows, glow, text, button
background. Centered icon fills 85 percent square canvas. Bold simple shapes meant
for 20x20 pixel display.
