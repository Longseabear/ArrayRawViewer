# Array RAW Viewer 0.11.58

## 설치파일

- ArrayImageViewer.vsix: Visual Studio 2017 / 2019 / 2022 (amd64 포함)
- ArrayImageViewer-VS2015.vsix: Visual Studio 2015 전용

## 구조체 검색 안전장치

- 잘못된 클래스/템플릿 이름으로 탐색할 때 자식 멤버 열거도 최대 64개로 제한합니다. null 또는 디버거 표시용 항목도 제한에 포함합니다.
- 처리 대기열까지 64개 노드 예산에 포함하고, 디버거 호출 사이에서 3초 탐색 예산을 검사합니다.
- 루트 표현식 평가 요청의 타임아웃을 500ms로 줄였습니다.
- uint16, uint16_t 등 정수 별칭 포인터·배열을 RAW 저장소로 취급하여 재귀 탐색에서 제외합니다.
- 한도 초과 시 타입 이름과 검색 루트를 확인하도록 오류를 표시합니다.

## 사용 시 주의

템플릿 인자를 포함한 디버거 타입 이름으로 등록하세요. 예를 들어 CInputStream<unsigned short>로 표시된다면 해당 이름을 사용합니다. 범용 <T> 매칭은 지원하지 않습니다.

무한/null 자식 열거와 시간 예산 검사 회귀 테스트를 포함합니다. 실제 사용자 프레임워크에서 보고된 정지 현상은 아직 재현 검증하지 않았습니다. VS 내부의 단일 COM 호출 자체가 멈추면 강제로 중단할 수 없으므로 3초는 절대적인 UI 응답 보장이 아닙니다.
