# Array RAW Viewer 0.11.61

## 설치파일

- **ArrayImageViewer.vsix**: Visual Studio 2017 / 2019 / 2022 (amd64 포함)
- **ArrayImageViewer-VS2015.vsix**: Visual Studio 2015 전용

## Structure Templates 옵션 오류 수정

- 클래스 이름 셀을 편집한 뒤 Enter를 누르거나 창의 포커스를 바꿀 때 Visual Studio가 멈추던 문제를 수정했습니다. 원인은 구조체 검색이 아니라, 네이티브 옵션 창이 표 내부 편집창으로 이동하는 데 필요한 `WS_EX_CONTROLPARENT` 누락이었습니다.
- 옵션을 닫았다 다시 열면 “이 속성 페이지를 로드하는 중 오류가 발생했습니다”가 나오던 문제를 수정했습니다. 옵션 창을 닫을 때 컨트롤을 폐기하지 않고, 다음 활성화 시 솔루션별 설정 데이터만 새로 불러옵니다.
- Enter는 현재 셀의 입력만 확정하며 옵션 창의 기본 버튼으로 전달되지 않습니다. 새 템플릿을 추가하면 클래스 이름 입력창에 포커스를 둡니다.
- 솔루션이 없는 상태의 식별자를 파일 경로로 처리하면서 발생할 수 있는 옵션 로드 예외를 방지했습니다.

## 검증

- 이전 DLL에서 네이티브 옵션 호스트의 포커스 전환 멈춤을 재현하고, 수정 DLL에서 정상 종료를 확인했습니다.
- 셀 입력 및 Enter, 닫기/재활성화/재편집 3회 회귀 테스트와 코어 테스트를 통과했습니다.
- 로컬 VS2022에 설치한 DLL과 수정 빌드의 일치를 확인했습니다. 실제 VS에서 수정 후 전체 재현 절차의 최종 UI 검증은 아직 완료하지 않았습니다.
