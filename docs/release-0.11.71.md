# Array RAW Viewer 0.11.71

## 이미지 중심 UI

- Array Viewer 왼쪽, Frame / Structure / Profiles 설정과 Frame map 오른쪽으로 재배치했습니다. 별도 창 없이 한 화면에서 설정하고 관찰할 수 있습니다.
- 경계선을 드래그해 이미지와 설정 패널의 너비를 조정할 수 있습니다.
- 핵심 기능인 **Run to write (Watch)**와 X/Y 이동을 이미지 위에 유지했습니다. 선택한 픽셀에 값이 쓰이는 순간 멈추고 확인하는 기존 동작은 유지합니다.
- Source 메뉴를 정리하고 좁거나 낮은 창에서도 도구와 설정이 겹치지 않도록 레이아웃을 조정했습니다.
- Frame map을 기본으로 표시하며, Stats는 필요할 때만 펼칠 수 있습니다.

## Array 탭 및 디버거 안정성

- 밑줄이 포함된 Array 탭 이름을 클릭할 때 WPF 인라인 텍스트가 잘못된 시각 트리 검사로 전달되는 예외를 수정했습니다. 같은 탭을 다시 클릭하는 경우도 보호합니다.
- 탭 전환 때 모든 헤더를 다시 만들지 않고 기존 헤더와 포커스를 유지합니다.
- 디버거 실행·종료 시 예약된 읽기와 오래된 UI 갱신을 취소하도록 보강했습니다.
- 하드웨어 데이터 중단점은 생성 전 목록과 식별 정보를 추적하고, 소유권이 불분명한 중단점을 임의로 삭제하지 않도록 보강했습니다.

## 검증 및 범위

- 실제 WPF 컨트롤의 탭 텍스트 입력 이벤트 회귀 테스트, 탭 전환, 중단점 소유권 테스트 및 600 / 900 / 1200px 레이아웃 검증을 포함합니다.
- VS 2022에서 새 설치본을 설치하고 UI를 확인했습니다. 사내 PC의 종료 현상과 모든 네이티브 디버거 조합이 재현·검증된 것은 아닙니다.
- VS 2015 전용 패키지는 별도 빌드합니다. VS 2015 실환경 검증은 수행하지 않았습니다.

## 설치파일

- **ArrayImageViewer.vsix**: Visual Studio 2017 / 2019 / 2022 (VS 2022 amd64 포함)
- **ArrayImageViewer-VS2015.vsix**: Visual Studio 2015 전용

Visual Studio를 종료하고 해당 버전의 VSIX를 설치한 뒤 다시 실행하세요.
