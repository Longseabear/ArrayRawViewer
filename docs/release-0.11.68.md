# Array RAW Viewer 0.11.68

## 구조체 검색 최적화

- 예제 확인을 위한 중복 루트 평가를 제거했습니다.
- 항목별 Task.Delay 대신 약 40ms 간격으로 UI 실행 기회를 제공합니다.
- 검색 안에서 타입 매칭/확장 판단을 재사용합니다.
- 명확한 단일 포인터의 주소+타입을 기준으로 중복 확장을 방지합니다. 주소를 해석할 수 없으면 기존 제한 아래 탐색합니다.
- Search objects가 매번 현재 솔루션의 저장된 정의를 읽습니다. Remember for solution과 분리했으며 이전 검색 결과 캐시는 재사용하지 않습니다.
- Viewer 전체 비활성화를 제거하고 검색 버튼/루트 입력만 잠급니다. Cancel search를 추가했습니다.
- 검색 중 자동 이미지 갱신 타이머 처리를 보류합니다.

## 검증 및 제한

스칼라 50개, 깊이 8의 타겟, 순환 포인터를 포함한 모의 디버거 탐색과 코어/옵션/Viewer 회귀 테스트를 검증했습니다. 실제 사용자 환경의 속도 개선 폭은 미확인입니다. 개별 디버거 COM 호출은 즉시 취소되지 않을 수 있습니다.

## Array 탭 전환 안정화

- 캐시된 Array 탭 복원에서는 Frame map 디버거 읽기를 시작하지 않습니다.
- 전환 시 자동 갱신/좌표/오버레이 타이머를 중지하고 통계 및 검색 컨텍스트를 무효화합니다.
- 지연된 스크롤 복원은 동일 탭과 렌더 세대일 때만 적용합니다.
- 탭 이벤트 및 스크롤 콜백의 예외를 상태 메시지로 처리합니다.
- 빈 탭은 이전 탭의 캔버스 크기와 좌표를 남기지 않습니다.

수정 전 빌드에서 Frame map 캐시가 없는 탭 복원 중 디버거 예외가 전파되는 테스트 실패를 확인했습니다. 수정 후 동일 조건에서 추가/12회 왕복/닫기 테스트가 통과했습니다. 사용자 환경의 실제 종료 기록과 동일한 원인인지까지 확정한 것은 아닙니다.
