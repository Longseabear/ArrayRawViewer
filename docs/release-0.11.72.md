# Array RAW Viewer 0.11.72

## Watch X/Y 안정성

- 생성 API가 반환한 중단점 객체를 보관하여 주소 문자열만으로 다시 찾던 의존성을 줄였습니다.
- 삭제 요청과 삭제 완료 확인을 분리했습니다. 비동기 삭제 중에는 중복 Delete를 보내지 않고, 해제 확인 후 다음 Watch를 등록합니다.
- Clear가 해제 대기 목록까지 처리하며, 자동 해제 실패를 성공으로 표시하지 않습니다.
- 디버깅 종료 시 미해제 Watch의 소유 정보를 유지하고, 정지 상태가 아닌 경우 예약된 Watch를 취소합니다.
- 소유권이 불분명한 동일 주소 중단점이나 사용자 중단점은 임의로 삭제하지 않습니다.

## 전역 템플릿과 옵션 저장

- Tools > Options > Array RAW Viewer > Structure Templates에 Global / Current solution 범위를 추가했습니다. 전역 정의를 기본으로 사용하고 동일 클래스는 솔루션 정의가 우선합니다.
- Enter는 입력만 확정합니다. Save 또는 Visual Studio 옵션의 확인 버튼으로 저장하고 Viewer에 자동 반영합니다.
- 여러 범위의 편집 내용을 한 번에 저장하고, 전체 저장 완료 후 변경을 알립니다. 입력 오류는 셀과 상태 문구로 표시합니다.
- 옵션 UI, 저장 및 키보드 처리를 분리했습니다.

## 검증 및 한계

- 중단점 검사 22개, X/Y 교대 50회 비동기 삭제 모의 테스트, UI 및 코어 회귀 테스트 통과.
- 일반 패키지와 VS 2015 호환 패키지 빌드 완료.
- 실제 Visual Studio에서 이번 버전의 반복 Watch 조작 및 VS 2015 실환경 검증은 아직 수행하지 않았습니다. 모의 테스트가 모든 네이티브 디버거의 동작을 보장하지는 않습니다.
- 이전 확장 인스턴스가 남긴 소유권 불명의 중단점은 자동 삭제하지 않습니다.

## 설치파일

- **ArrayImageViewer.vsix**: Visual Studio 2017 / 2019 / 2022 (VS 2022 amd64 포함)
- **ArrayImageViewer-VS2015.vsix**: Visual Studio 2015 전용

Visual Studio를 종료하고 해당 버전의 VSIX를 설치한 뒤 다시 실행하세요.
