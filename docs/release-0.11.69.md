# Array RAW Viewer 0.11.69

## 변경 사항

- 구조체 검색에서 기반 클래스 항목을 매칭 및 하위 탐색 전에 제외합니다. 제외 사유는 debug dump의 SKIP base-class entry에 기록됩니다.
- Search objects를 돋보기 아이콘으로 변경했습니다. 검색 중 동일 버튼이 취소 아이콘으로 바뀌고 옆의 고정 폭 상태 문구를 표시합니다.
- 로딩 막대 및 검색 중 입력창의 비활성/읽기 전용 처리를 제거했습니다. 루트를 수정하면 진행 중인 결과는 적용하지 않습니다.
- 이전 버전의 검색 최적화, 옵션 재로딩, Array 탭 복원의 디버거 재읽기 차단과 예약 작업 보호를 포함합니다.

## 제한 및 검증

기반 클래스 판별은 DTE에서 타입명과 같은 이름으로 표시되는 비포인터 자식 항목을 기준으로 합니다. 일반 멤버 이름도 타입명과 같은 특수한 경우에는 구분에 한계가 있습니다. 해당 객체를 루트로 직접 바인딩할 수 있습니다.

코어/모의 디버거 탐색/옵션/UI 및 Array 탭 왕복 회귀 테스트를 확인했습니다. 다른 PC에서 보고된 VS 종료 문제의 완전한 해결은 아직 확인되지 않았습니다.
